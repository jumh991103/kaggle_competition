# 🚢 Titanic Dataset Description

> 캐글 타이타닉 경진대회 데이터셋 컬럼 설명 정리

<br>

## 📋 데이터 컬럼 설명

| 컬럼명 | 데이터 타입 | 설명 | 값의 의미 |
|---|---|---|---|
| `passengerid` | 정수형 | 승객을 구분하기 위한 고유 번호 | 승객별로 부여된 ID |
| `survived` | 정수형 | 승객의 생존 여부를 나타내는 목표 변수 | `0`: 사망, `1`: 생존 |
| `pclass` | 정수형 | 승객이 이용한 객실 등급 | `1`: 1등석, `2`: 2등석, `3`: 3등석 |
| `name` | 문자열 | 승객의 이름 | 성명과 호칭 등이 포함됨 |
| `gender` | 문자열 | 승객의 성별 | `male`: 남성, `female`: 여성 |
| `age` | 실수형 | 승객의 나이 | 단위: 세, 일부 결측값 존재 |
| `sibsp` | 정수형 | 함께 탑승한 형제자매 및 배우자 수 | 0 이상 정수 |
| `parch` | 정수형 | 함께 탑승한 부모 및 자녀 수 | 0 이상 정수 |
| `ticket` | 문자열 | 승객의 승선권 번호 | 숫자 또는 문자와 숫자의 조합 |
| `fare` | 실수형 | 승객이 지불한 승선 요금 | 단위: 당시 영국 파운드 |
| `cabin` | 문자열 | 승객이 사용한 객실 번호 | 객실 번호, 다수의 결측값 존재 |
| `embarked` | 문자열 | 승객이 탑승한 항구 | `C`: 셰르부르, `Q`: 퀸스타운, `S`: 사우샘프턴 |

<br>

## 🔑 주요 용어 설명

- `sibsp`는 **Sibling/Spouse**의 약자로, 함께 탑승한 형제자매와 배우자의 수를 의미함
- `parch`는 **Parent/Child**의 약자로, 함께 탑승한 부모와 자녀의 수를 의미함
- `embarked`는 승객이 타이타닉호에 탑승한 항구를 의미함
- `survived`는 머신러닝 모델이 예측해야 하는 **목표 변수(Target)**임
- `age`, `cabin`, `embarked` 컬럼에는 결측값이 포함될 수 있음
